# Skill installate

Quattordici skill di marketing e contenuti, usate per costruire il kit.

**Nel repo:** le definizioni operative di `hook-writer`, `tiktok-script`, `reels-script` e `content-calendar`.
**Nel pacchetto completo:** tutte le 14 skill con `references/`, `evals/` e file di supporto (96 file, 884 KB).

## Elenco

| Skill | A cosa serve |
|---|---|
| `brand-profile` | Profilo di marca: pubblico, posizionamento, voce. |
| `voice-builder` | Costruisce la voce editoriale da esempi reali. |
| `hook-writer` | Hook per caption, video, caroselli, thread. |
| `tiktok-script` | Script nativi TikTok, hook a 1 secondo, loop. |
| `reels-script` | Script Reels, sound-off, watch-through, sends. |
| `carousel-writer` | Caroselli slide per slide, con brief visivo. |
| `content-calendar` | Ritmo di pubblicazione sostenibile e serie ricorrenti. |
| `cross-platform-repurposing` | Adatta un contenuto a più piattaforme. |
| `social-seo` | Ricerca e keyword per i motori interni delle piattaforme. |
| `link-in-bio-and-traffic` | Link in bio, traffico, percorsi di click. |
| `copywriting` | Copy persuasive, framework e controllo degli AI-tell. |
| `social` | Strategia social, formati, analisi dei post. |
| `offers` | Costruzione dell'offerta, garanzie, scarsità. |
| `launch` | Lancio di prodotto, checklist e QA del sito. |

## Come si usano

Ogni skill è una cartella con `SKILL.md`. Il frontmatter contiene `name` e `description`; il corpo contiene procedura, quality bar, edge case e riferimenti.

Per installarle in un altro progetto, copia `.agents/skills/` nella root del progetto. Il pacchetto completo è in `freebuff-kit-full.zip`.

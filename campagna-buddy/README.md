## Regole comuni

- Un account per persona.
- Niente referral comprati, niente spam in DM.
- Disclosure sempre visibile.
- Il premio è di Freebuff, non tuo: "sto provando ad arrivare a 600 inviti".
- Se un'offerta scade, aggiorna il contenuto o mettilo offline.

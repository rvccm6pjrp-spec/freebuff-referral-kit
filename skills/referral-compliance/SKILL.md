# Referral Compliance

A referral link that gives the poster a benefit is **commercial communication**. The rules
that matter are three: say it clearly, put the link where the platform allows it, and do not
behave like a spam account. Most bans come from the third one, not from the link itself.

This is operational guidance, not legal advice. For a regulated claim or a large paid
campaign, have a lawyer or compliance reviewer check it.

## The disclosure

Use plain language, visible before the fold or in the first lines:

> **ADV:** link referral personale. Se lo usi ricevo sessioni extra; per te il prezzo non cambia.

or

> #adv — se passi dal mio link ricevo un beneficio.

Rules:

- Put it in the post, not only in the profile.
- Do not hide it among 30 hashtags or in a collapsed "show more".
- On TikTok, enable **Contenuto commerciale / Branded content** when the option is offered.
- On Instagram, use **Collaborazione retribuita** / the branded-content label when the
  relationship is commercial; add `#adv` in the first line.
- On YouTube, tick **Contenuto a pagamento** when there is an incentive, and label the link
  `Link referral (ADV)`.
- On X and LinkedIn, write `ADV` or `referral` next to the link.

## Where the link can go

| Platform | Clickable placement | Do not |
|---|---|---|
| Instagram | Bio; link sticker in Stories | Put a raw URL in caption/comments expecting clicks |
| TikTok | Website field in bio, if available | Link comments, repetitive comment replies |
| YouTube Shorts | Channel links; pinned text comment | Assume description/comment URLs are clickable |
| YouTube long-form | Description, channel links | Comment spam on other channels |
| X | Post, profile, follow-up post | Identical replies, misleading redirects |
| LinkedIn | Post or first comment, profile | Mass invites, promotional comments on others' posts |
| Reddit | Only where the subreddit allows it | Assume referral links are welcome; most subs ban them |
| Discord | Dedicated self-promo channel | DMs, general channels, identical messages across servers |
| GitHub | Your README/profile | Issues or PRs on other people's repos |

## Never do

- Comment the link under other people's posts, even once.
- Send unsolicited DMs, or the same DM to many people.
- Use multiple accounts, buy referrals, or refer yourself.
- Promise earnings, a guaranteed prize, or a MacBook unless the program explicitly states it
  and you can prove it.
- Use fake urgency ("solo oggi") that resets every day.
- Hide the referral relationship or use a redirect that disguises the destination.
- Post the same link in five subreddits or five Discord servers in one hour.

## Pre-publish checklist

- [ ] The link is in a clickable placement the platform allows.
- [ ] The disclosure is visible in the post, in plain language.
- [ ] The commercial-content toggle is on where required.
- [ ] No link in comments of other accounts.
- [ ] No unsolicited DMs.
- [ ] One account, one referral link.
- [ ] Prices/offer verified today.
- [ ] The post would still be useful if the link were removed.

If the last box is unchecked, the post is an ad with no content. Rewrite it.

## If someone objects

Reply once, without defensiveness:

> Sì, è un link referral: se lo usi ricevo sessioni extra, a te non costa niente. Il prodotto
> è gratis e puoi usarlo anche senza il mio link.

Then stop. Do not argue in the comments, do not delete legitimate criticism, do not ask
others to defend you.

## Output

A pass/fail table with the eight checklist items, the exact disclosure text to paste, and
the one placement to use. If something fails, say what to change before publishing.
